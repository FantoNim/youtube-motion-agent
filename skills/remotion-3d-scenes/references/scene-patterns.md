# Tested scene patterns

- World units are meters-like units; floor y=0, walls behind z<0, camera starts at [6.4,4.3,7.5], ends [4.2,4.05,8.7], looks at [0,1.05,-0.3], perspective 38 degrees. Camera path uses smoothstep over frames 0–149 at 30fps. It is not a custom renderer: Three.js handles projection, materials and shadows through R3F/ThreeCanvas.
- camera-path.mjs is pure frame-indexed math shared by TS source and Node tests. CameraRig obtains the R3F camera, updates position/lookAt/matrix in useLayoutEffect keyed by frame, before ThreeCanvas's effect-based advance/capture. Test same frame after arbitrary seeks and in fresh browsers.
- Layering: room base and planks, back wall/menu, espresso counter and machine, foreground tables/cups/chairs, plants and pendant. Distinct depth planes establish parallax and occlusion. Procedural cubes/cylinders/torus/spheres provide actual geometry without external assets.
- Lighting: ambient + hemisphere fill, warm directional key casting PCF soft shadows (1024 square map), point-light pendant fill. Use castShadow on objects and receiveShadow on floor/table surfaces. Tune shadow frustum/bias/normalBias, near/far and exposure; do not call a baked dark shape a rendered shadow. Shadow enablement is logged and visibility must be inspected.
- Standard materials: rough wood/walls, smoother glazed cups, high-metalness espresso body/pendant. Three's SRGB output and ACESFilmic tone mapping are explicit; encoded H.264 uses BT.709/yuv420p. This is a stylized procedural material test, not photorealism or reference-style matching.
- No controls, physics, TTS, music, particles, external models, texture/video loaders or fonts are required. Arial is a documented local system font fallback for optional test labeling; no font network requests. Never put production metadata on learner-facing content by default; the on-screen test label is specific to this silent synthetic fixture.
- Keep DOM titles outside ThreeCanvas. Native mesh text/HTML inside the R3F tree is not automatically supported. Use Sequence layout="none" inside the canvas. If adding async assets later, use approved local staticFile paths and verify loading/delayRender behavior; this template does not prove video-texture synchronization or WebGPU support.

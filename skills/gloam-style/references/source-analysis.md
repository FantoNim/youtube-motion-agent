## Dimensional classification

- **2D:** SVG/vector-like lines, outline icons, bars, chart paths, serif statistics, clock text and flat process diagrams (G07/G09/G11). Can be built without 3D.
- **2.5D:** planar paper/screenshot/quote cards with tilt, offset soft shadow, overlap, blurred motion and focal hierarchy (G03/G05/G08/G10). CSS/DOM transforms or camera-facing planes are sufficient; a tilted image is not a full modeled room.
- **Spatial / real-3D-looking:** vault-room views, modeled-looking doors/plinths/coins/cash register and storage arrays with perspective, occlusion, materials and lighting (G02/G04/G06/G11/G12). The visible dimensional behavior warrants genuine geometry when recreating these shots. **Provenance remains unknown:** source project files are unavailable, so actual mesh authoring, AI-assisted plates, renderer, physical simulation, rigging or real-time capability cannot be certified from the encode. An adaptation may be honestly called real 3D only after it actually uses and verifies scene geometry/camera/lights—not because the reference looks 3D.

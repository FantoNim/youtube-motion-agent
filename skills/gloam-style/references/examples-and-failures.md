# Examples, selection rules and failure modes

Examples below are **original adaptation briefs**, not rendered demos, source recreations or verified factual stories. Invented example content stays explicitly illustrative. Use the actual supplied narration, evidence and timings in production.

## Example 1 — “A small permission changed the whole system”

- Function: explain authority, not celebrate hacking.
- Plan: cream board with system icon left, authorization note center, controller right; draw one red control curve and change the affected system's state. Hold while the narration finishes the explanation. If speech then introduces a doorway analogy, cut to original geometry showing a hinged door under new control.
- Source connection: G07 and its locally checked ASR analogy cue.
- Deliverable needed: verified project cue, diagram labels/claim source, a precise definition of the changed permission, and sample approval. Not “any wallet can always be emptied” or an execution tutorial.

## Example 2 — “What happened before, during and after?”

- Function: communicate chronology with no time-zone ambiguity.
- Plan: three calendar cards → amber timestamp on dark → one active card in a row → a stable timeline with three meaningful events. Qualify estimated times. Return to the same object's changed state for aftermath.
- Source connection: G05/G09, not a fixed 30-second template.
- Failure to avoid: using a ticking countdown that implies measured real-time footage when the scene is only illustrative. Label compressed time and keep program time separate from event time.

## Example 3 — “Evidence supports a hypothesis, not certainty”

- Function: preserve qualification, not make a dramatic accusation.
- Plan: anonymous folder with known/unknown labels; two evidence cards and one alternative explanation; comparison panel under a visibly qualified headline. Use red for the analytic focus, not “guilty.”
- Source connection: G10. Use approved new text/data, not source names/claims.
- Failure to avoid: a real person's portrait plus red criminal stamp without substantiated authority. Don't render fake official social/news screenshots to imply external validation.

## Example 4 — “An object is a recurring explanation”

- Function: memory through continuity.
- Plan: original storage room/assembly at setup, controlled state change during mechanism, same topology in aftermath, quiet return at ending. If the topic isn't financial, use a domain-relevant container/queue/permission object rather than force coins into it.
- Source connection: G02/G04/G06/G11/G12.
- Failure to avoid: disconnected 3D set pieces with no consistent scale, materials or causal relationship. A giant orbiting metallic logo is not the observed style.

## Example 5 — Closing contrast

- Function: make the main contrast memorable and finish the sentence.
- Plan: two short large-figure cards, pale then red, a clear final statement with optional italic second line, then a small unobtrusive CTA while the statement remains readable. Times follow the actual recording; no automatic fixed-length outro.
- Source connection: G12. No source wording/numbers need to be copied.
- Failure to avoid: ending while a digit is still blurred, CTA covering the conclusion, cutting the last narrated word, or labeling a static final card as “cinematic camera movement.”

## Common regressions and the repair

- **All-black cyberpunk:** loses light dossier/gray analytic boards. Restore the appropriate reading field and paper hierarchy.
- **All-cream slides:** loses the spatial/contrast dimension. Use an intentional dark/statistic or original geometry beat only when meaning warrants it—not an arbitrary quota.
- **Exact-match font/color claims:** unsupported. Name the chosen substitutes/tokens as recommendations; verify actual font files and encoded color.
- **3D claim from a picture:** use genuine geometry/camera/lights and inspect motion, or say plate/2.5D. Source authoring provenance is unknown.
- **Microscopic metadata treated as accessible copy:** enlarge/remove it. Source-like atmosphere is not permission for unreadable important caveats.
- **Paper clutter:** collapse to one main slab plus one annotation; give the reader a stable hold.
- **Fake evidence:** use real approved evidence with rights/provenance or an unmistakably labeled illustration. A visual reconstruction must not masquerade as a recording of the event.
- **Unverified ASR names/numbers:** recheck or omit; broad phrase alignment isn't exact word sync.
- **Sound copied from imagined mood:** no timbre/music observations were established. Treat audio as a separate approved brief.
- **Presenter added everywhere:** the source isn't an avatar explainer. No host unless requested; then follow the user's current scoped identity/gesture constraints.
- **Screen footage fills frame by default:** current user preference overrides that source behavior. Frame/crop relevant excerpts unless full-frame is explicitly requested.
- **Full render before approval:** render a representative sample and wait unless waived. A technical synthetic fixture is not style approval.

## Practical acceptance question

Could another editor reproduce the selected look and explain why every object, annotation, cut and camera move is there from the brief/shotlist/spec alone? If not, specify the missing rule instead of adding more adjectives.

## New-production ordered workflow

1. Probe the supplied original/master: audio/video durations, start offsets, tracks, channels and trailing time. Preserve originals. For cleanup, route to the actual local long-form cleanup workflow first; graphics must use post-edit program time and the cut map. **Check:** measured master and source/program mapping exist.
2. Use a supplied script if present, but the recording is the clock. With no script, use an existing verified local ASR workflow and manually recheck uncertain words by an available listening/visible-source route. If no reliable transcript/listening route exists, label the gap and avoid claims of exact cue sync; don't fabricate speech. **Check:** real cue ranges and uncertainty are recorded.
3. Break speech into idea units, not arbitrary equal-duration slots. Label each as evidence, mechanism, chronology, comparison, implication, qualification, status or CTA. Preserve breaths and important qualifications. **Check:** every beat communicates one main idea.
4. Select one visual action per cue: identify an object, reveal a row, draw a relation, change a state, annotate the evidence or cut to a changed scale. A supporting hold is a valid visual. Do not animate every syllable. **Check:** shotlist states the visual's communication job and why its cue occurs there.
5. Reserve time for entry, settling, reading and exit within the actual spoken beat. For a complex document, shorten the visible excerpt or hold longer; don't speed up narration or silently trim it. Some visuals can lead a phrase slightly for comprehension, but verify that this doesn't reveal an answer too early. **Check:** key text is stable while the audience must read it.
6. Place continuous narration at project level, not inside overlapping visual sequences. Preserve tail/audio longer than the last picture if present; supply an intentional held image rather than truncating the audio. Compute total duration from actual streams and record any final-frame rounding. **Check:** full master duration remains present, no duplicated/restarted phrase, no accidental blank tail.
7. Render and inspect a representative real-narration sample before full production. Objective audio probe/energy checks are not listening. If no listening route exists, report that sync/intelligibility were not aurally verified and do not claim those checks passed. **Check:** sample QA and approval state are explicit.
